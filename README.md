# FocusFlow – Responsive Landing Page

FocusFlow is a fictional productivity SaaS product designed to help users stay focused, manage tasks, and track their progress. This project is a modern, responsive landing page built as part of the **Elevvo Frontend Development Internship**.

## 🚀 Live Demo

[View Live Demo](#)
elevvo-focusflow-landing-page.netlify.app

## 📸 Features

* **Responsive Design:** Adapts to desktop, tablet, and mobile screens.
* **Dark and Light Mode:** Switch between themes using the theme toggle.
* **Hero Section:** Introduces FocusFlow with a dashboard preview.
* **Features Section:** Highlights the product's key features.
* **Pricing Section:** Displays Free, Pro, and Team plans.
* **Navigation:** Smooth navigation between page sections.
* **Interactive Elements:** Hover effects and theme switching.

## 💻 Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate into the project folder:

   ```bash
   cd focusflow-landing-page
   ```

3. Open `index.html` in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code.
